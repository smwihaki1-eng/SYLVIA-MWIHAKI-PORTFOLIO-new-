What's in this folder
  index.html                          the whole site (landing, work, case studies, wall, about, phone layout)
  b/                                  stickers, artwork and textures used by the page
  w/                                  case study images and the SKY Girls / Signs to Look Out For videos
  Sylvia_Mwihaki_Portfolio_2026.pdf   the PDF portfolio the buttons open
  Sylvia_Mwihaki_Sticker_Sheet.pdf    the printable sticker sheet (the prize at the last stop)
  vercel.json                         tells Vercel what kind of file each one in b/ is (keep it, or the stickers won't show)
  favicon.png, apple-touch-icon.png, og.jpg   tab icon, phone icon and link preview image

Put it on Vercel (drag and drop)
  1. Unzip this file. You'll get a folder called sylvia-mwihaki-portfolio.
  2. Go to vercel.com, sign in, then Add New → Project.
  3. Drag the sylvia-mwihaki-portfolio folder onto the page (or pick "Deploy from folder"). Leave the framework as "Other". No build command.
  4. Click Deploy. Vercel gives you a test link: open it and click around before going live.
  5. To put it on sylviamwihaki.com: Project → Settings → Domains, add the domain. If the domain is already on your current
     Vercel project, remove it there first (or simply upload these files into that project instead).

Good to know
  - Keep the folder structure as it is. Renaming or moving files in b/ or w/ will break images.
  - The page loads React, three.js and Google Fonts from their public CDNs, so it needs an internet connection (normal for a website).
  - Pages: #work-page, #about-me, #the-wall, #case-safaricom (and the other case names). Share those links directly.
